# O cofre como pasta de trabalho do Claude

Arquivos da aula:

| Arquivo | Para que serve |
|---|---|
| `cofre-aurora-wiki/` | O cofre de trabalho da Renata, com as pastas `fontes` e `wiki`, do jeito que estava antes do Claude. É o cofre da aula, para repetir os passos |
| `roteiro-git.md` | Os comandos do git na ordem da aula: o primeiro commit, o teste da trava, o desfazer antes e depois do commit |
| `modelos/CLAUDE-modelo.md` | O arquivo de esquema com as regras da aula e espaço para as suas |
| `modelos/settings-modelo.json` | A forma do `.claude/settings.json`, com os nomes de pasta para trocar pelos seus |
| `modelos/gitignore-modelo.txt` | O `.gitignore` da aula. Copie para a raiz do cofre com o nome `.gitignore` |
| `minha-entrega.md` | O que você entrega no exercício, em branco |

## Antes de começar

Você precisa do git e de um dos jeitos de o Claude abrir uma pasta: o Claude Code no terminal, a aba Code do aplicativo do Claude ou o Cowork. A aula diz o que cada um pede de plano, com a data e o link da página oficial. A trava por pasta é do Claude Code. No Cowork, ela fica como "não testado".

Copie a pasta `cofre-aurora-wiki` para fora do kit, por exemplo para os seus Documentos, e trabalhe na cópia. Abra o terminal e o Claude sempre na raiz da cópia. As regras de permissão contam a partir dela.

O cofre já traz as notas da Renata, as duas fontes (a ata de 12/10 e a mensagem da Clara de 03/12) e a wiki com a página `Política de trocas`, o `index.md` e o `log.md`. O `CLAUDE.md`, o `.claude/settings.json`, o `.gitignore` e o repositório git não vêm prontos: você faz na aula.

A ata de 12/10 tem um erro de digitação de propósito, "atendimeto". Ele é o alvo do teste da trava: o Claude não pode corrigir.

## Ajuda

Se travar, deixe um comentário na aula com o objetivo, o comando, o que apareceu e o que já tentou. Mande a saída do `git status` e o seu `settings.json`, sem o conteúdo das notas.
