# Conectores: Obsidian CLI, MCP e plugins

Arquivos da aula:

| Arquivo | Para que serve |
|---|---|
| `fichas.md` | Duas fichas de integração em branco, a escolha e a linha do teste, para o exercício |
| `roteiro-de-teste.md` | Os passos para testar uma conexão num cofre de teste e para revogar, por jeito de ligar |

Salve uma cópia do `fichas.md` fora do kit e preencha a cópia. Ele abre no Obsidian ou em qualquer editor de texto.

## O cofre de teste

Para testar, use uma cópia do `cofre-aurora-wiki`, do kit da aula «Montar e consultar uma LLM Wiki» (pasta `14-montar-e-consultar-uma-llm-wiki`). Copie a pasta inteira para outro lugar, com um nome como `cofre-teste-conector`, e trabalhe na cópia. Nunca teste no seu cofre de verdade.

Você não precisa instalar nada para fazer o exercício. A ficha se preenche lendo páginas. Instalar entra só no teste, e só se a ficha passar.

## As páginas que a aula usa

- [Obsidian CLI](https://obsidian.md/help/cli), na ajuda oficial do Obsidian;
- [Segurança de plugins](https://obsidian.md/help/plugin-security) e [diretório da comunidade](https://obsidian.md/help/community-directory), na mesma ajuda;
- [MCP no Claude Code](https://code.claude.com/docs/en/mcp) e [permissões](https://code.claude.com/docs/en/permissions);
- os repositórios das fichas da aula: [iansinnott/obsidian-claude-code-mcp](https://github.com/iansinnott/obsidian-claude-code-mcp) e [rtm/obsidian-mcp](https://github.com/rtm/obsidian-mcp);
- para a opção da Aurora no exercício: [Local REST API with MCP](https://community.obsidian.md/plugins/obsidian-local-rest-api).

As páginas mudam. Anote na ficha o dia em que você leu.
