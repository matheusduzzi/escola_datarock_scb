# Organizar e destilar: PARA, nota atômica e resumo progressivo

Os arquivos dessa aula do curso Segundo cérebro com IA. Faça uma cópia da pasta `cofre-da-renata` antes de mexer: assim você pode começar de novo quando quiser.

## O que tem aqui

| Arquivo ou pasta | Para que serve |
|---|---|
| `cofre-da-renata/` | O cofre da Renata depois de uma semana de captura: 14 notas soltas na raiz, 4 na caixa de entrada e a pasta de modelos |
| `cofre-da-renata/Palestra - trocas e devoluções.md` | A nota longa que você destila em três camadas |
| `cofre-da-renata/Modelos/Nota atômica.md` | O modelo de nota atômica para as suas cinco notas |
| `minhas-decisoes.md` | A tabela onde você anota para onde foi cada nota e por quê |

## Como abrir

1. Copie a pasta `cofre-da-renata` para onde você guarda seus arquivos.
2. No Obsidian, abra o menu do cofre no canto de baixo, à esquerda, escolha gerenciar cofres e abra a pasta copiada como cofre. Na ajuda do Obsidian, em inglês, o caminho é Manage Vaults, Open folder as vault.
3. Para usar o modelo de nota, ligue o plugin Templates nas configurações e aponte a pasta de modelos para `Modelos`. A aula «O primeiro cofre no Obsidian» mostra esse passo.

Mova as notas pelo explorador de arquivos do próprio Obsidian: arraste a nota até a pasta ou clique nela com o botão direito e escolha mover (Move file to... na ajuda em inglês).

Sem o Obsidian, dá para fazer tudo com um editor de texto e as pastas do computador. As notas são arquivos Markdown, com extensão `.md`. O negrito é `**texto**` e o realce é `==texto==`; num editor comum você vê os símbolos, não a cor.
