# Kit de Segundo cérebro com IA

Comece pela pasta `00-apresentacao`. Ela tem o caso, as tarefas de preparação, um arquivo para as suas respostas e a sua ficha inicial.

1. Abra [o caso](00-apresentacao/caso.md) num editor de texto.
2. Leia [as tarefas](00-apresentacao/diagnostico.md).
3. Salve uma cópia de [minhas-respostas.md](00-apresentacao/minhas-respostas.md) e responda nela.
4. Salve uma cópia de [ficha-inicial.md](00-apresentacao/ficha-inicial.md) e preencha sobre você: onde suas anotações estão hoje, o que você perde com isso e o que quer recuperar.
5. Volte à apresentação do curso e escolha a primeira aula.

Para a preparação, você não precisa instalar nada. Os arquivos são texto em Markdown, com extensão `.md`: abrem em qualquer editor de texto. É o mesmo formato das notas do Obsidian, que você instala na aula 05.

Cada aula com prática tem uma pasta com o número e o nome da aula, por exemplo `05-o-primeiro-cofre-no-obsidian`. Os caminhos do texto da aula partem dessa pasta. O kit traz hoje os arquivos da preparação. Os das outras aulas entram aqui conforme as aulas saem; não procure o que ainda não está listado.

O que vem nas próximas pastas:

- um cofre de exemplo da Loja Aurora, com projetos, reuniões, pessoas e leituras, que muda de aula para aula;
- modelos de nota para copiar para o seu cofre;
- 12 textos curtos para montar a LLM Wiki;
- o modelo do arquivo de esquema, com as regras que o Claude segue no cofre.

A Loja Aurora, a equipe e os textos são inventados para o curso, sem dado de cliente ou de pessoa. Os textos foram escritos para a Escola Datarock. A licença de redistribuição do kit ainda vai ser definida.

Para pedir ajuda, deixe um comentário na aula com o seu objetivo, o que você fez, o que apareceu e o que já tentou. Use os dados do caso, sem dados pessoais.
